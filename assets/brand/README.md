# Suffuse identity

The Suffuse mark shows a precise source becoming an atmospheric field inside a
defined boundary. The source and boundary express explicit control; the three
expanding arcs express spatial light without implying frame-rate animation or a
particular fixture.

## Repository palette

| Role | Color | Source |
| --- | --- | --- |
| Night | `#24134F` | First band of the bundled `dusk` palette |
| Ember | `#D05B58` | Third band of the bundled `dusk` palette |
| Glow | `#F2A65A` | Fourth band of the bundled `dusk` palette |
| Cream | `#FFF5E6` | High-contrast boundary and source |

Use the complete mark on its night background. Do not recolor individual arcs,
remove the boundary, or present the symbol as evidence that a physical lighting
effect rendered successfully.

## Voice

Suffuse is atmospheric, precise, and evidence-led. Prefer concrete verbs such
as *inspect*, *compile*, *preview*, *apply*, and *restore*. Avoid claims that an
API response proves visible output, that all Govee devices behave alike, or that
Suffuse is a real-time music-lighting engine.

This is intentionally a repository-scale identity: one mark, the project name,
the existing dusk palette, and a consistent editorial voice. It does not define
app-store, social, or commercial brand systems.

## Open Graph card

`suffuse-og.svg` is the editable 1200×630 source. The checked-in
`suffuse-og-1200x630.png` is the upload asset for GitHub's repository social
preview and other Open Graph surfaces. It leads with the two core surfaces—MCP
server and Agent Skill—while keeping the mark and palette unchanged.
